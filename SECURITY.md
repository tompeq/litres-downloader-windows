# Конфиденциальность и сообщения о проблемах

## Что не следует публиковать

- Логины, почту пользователя, пароли, токены и cookies.
- `.env`, конфигурацию с учётными данными, HAR, браузерный профиль, сессионное хранилище.
- Книги, страницы, изображения, локальные кэши, отчёты конкретных выгрузок.
- Полные адреса читалки с параметрами аккаунта, приватные пути и диагностические дампы.
- Скриншоты аккаунта, журналы терминала или истории команд без предварительного обезличивания.

Пароль вводится через скрытый запрос в терминале. Для логина тоже можно использовать интерактивный запрос, не передавая его через аргументы командной строки. Постоянный профиль Chrome не используется; временный профиль браузера может содержать сессионные данные во время работы и после аварийного завершения.

## Перед коммитом

1. Проверьте список: `git status --short` и `git diff --cached --name-only`.
2. Запустите `python scripts/check_publication.py` после добавления выбранных исходников в индекс.
3. Прочитайте `git diff --cached` целиком.
4. При публикации существующей истории дополнительно проверьте все коммиты стандартным сканером секретов, например Gitleaks.

`.gitignore` разрешает только явно перечисленные исходники и документы. Он не удаляет ранее отслеженные файлы и может быть обойдён через `git add -f`. Проверка `check_publication.py` выявляет лишние отслеживаемые файлы, но также не заменяет ручной просмотр и проверку истории.

## Как сообщить об ошибке

Для обычной ошибки создайте issue с версией Python/Chrome, условной командой и обезличенным сообщением. Реальные книги и учётные данные для воспроизведения не нужны: по возможности используйте синтетический пример структуры.

Не публикуйте секреты даже для сообщения об их утечке. Если секрет уже попал в публичный Git-коммит или issue, сначала отзовите/замените его у соответствующего сервиса. Удаление строки из последнего коммита не удаляет её из истории.

## Границы автоматической проверки

Проверка ищет некоторые форматы токенов, закрытые ключи, явно заданные значения паролей и реальные почтовые адреса. Произвольный секрет может не соответствовать этим шаблонам. Отсутствие находок означает, что проверяемые шаблоны не сработали; окончательное решение о публикации требует просмотра файлов.
