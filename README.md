# litres-downloader-windows

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Загрузчик для **Windows**, который сохраняет доступную вашему аккаунту книгу из **текстовой читалки Литрес** в **EPUB и PDF**. Текст остаётся выделяемым и доступным для поиска; иллюстрации и сноски включаются в файл.

Проект развивает идею [fennr/litres_download](https://github.com/fennr/litres_download). Исходный инструмент загружает изображения из PDF-читалки. Здесь реализована отдельная загрузка текстовой версии на основе данных FB3 JSON, которые получает обычная читалка.

В репозитории находятся только программа, документация и синтетические тесты. Книг, данных аккаунтов и сохранённых сессий в комплекте нет.

## Возможности

- Вход по логину или электронной почте и паролю через сайт Литрес.
- Автоматическое определение адреса текстовой читалки из карточки книги.
- Загрузка всех частей, перечисленных в оглавлении, с проверкой порядка, диапазонов и количества блоков.
- Сохранение заголовков, абзацев, выделений, изображений и сносок.
- **EPUB 3** с оглавлением, отдельными разделами и встроенными иллюстрациями.
- **PDF A4** с выделяемым текстом, номерами страниц и новой вёрсткой.
- Сноски в конце соответствующего раздела, со ссылками из текста.
- Локальный отчёт о выгрузке: количество частей, блоков, разделов, изображений, сносок и SHA-256 изображений.
- Необязательный кэш содержимого для повторного экспорта без входа в аккаунт.
- Тайм-ауты, ограниченные повторы сетевых запросов и проверка изображений перед сохранением.

Программа не оформляет покупки или подписки и не предоставляет доступ к отсутствующим в аккаунте книгам. Используйте её для содержимого, доступ к которому у вас есть, с соблюдением условий сервиса и прав правообладателей. Лицензия MIT относится к коду программы, а не к загружаемым книгам.

## Требования

| Компонент | Требование |
| --- | --- |
| ОС | Windows 10/11; инструкции рассчитаны на PowerShell |
| Python | Рекомендуется Python 3.12, на нём выполнены проверки |
| Браузер | Установленный Google Chrome |
| Аккаунт | Вход по почте/логину и паролю; доступ к нужной книге |
| Интернет | Для сайта, установки зависимостей и первого получения ChromeDriver |

Python-пакеты зафиксированы в [`requirements-text.txt`](requirements-text.txt). Selenium автоматически подбирает ChromeDriver. При использовании `uv` сценарий может скачать Python 3.12, если его нет локально.

## Быстрый старт

### 1. Получите исходный код

```powershell
git clone https://github.com/tompeq/litres-downloader-windows.git
cd litres-downloader-windows
```

Если Git не установлен, выберите **Code → Download ZIP** на странице репозитория, распакуйте архив и откройте PowerShell в полученной папке.

### 2. Запустите загрузку

Скопируйте **адрес карточки нужной книги** из браузера. В примерах ниже адрес условный: замените его реальной ссылкой.

```powershell
.\download-text.ps1 -Url 'https://www.litres.ru/book/author/book-123456/' -Name 'my-book'
```

Сценарий создаст изолированное окружение `.venv` и установит зависимости. Если доступен `uv`, он будет использован автоматически; иначе используется команда `python`.

Далее программа запросит логин и пароль. **Пароль вводится скрыто**: отсутствие символов на экране во время ввода нормально. Не добавляйте пароль в команду, README или конфигурационный файл.

Результаты появятся в `books` рядом с программой:

```text
books/
  my-book.epub
  my-book.pdf
  my-book.verification.json
```

Существующие файлы не перезаписываются. Для повторного запуска выберите другое имя или каталог.

### 3. При необходимости укажите каталог

```powershell
.\download-text.ps1 `
  -Url 'https://www.litres.ru/book/author/book-123456/' `
  -Name 'my-book' `
  -Output 'D:\Books'
```

`-Headful` показывает окно Chrome. Обычный запуск работает без видимого окна. Сложные сценарии с CAPTCHA, кодом подтверждения или сторонним провайдером входа могут потребовать доработки; автоматического прохождения таких проверок нет.

## Установка вручную

Если PowerShell запрещает запуск `.ps1`, можно обойтись командами Python без изменения системной политики выполнения:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-text.txt
.\.venv\Scripts\python.exe -X utf8 text_downloader.py `
  --url 'https://www.litres.ru/book/author/book-123456/' `
  --name 'my-book'
```

Активация виртуального окружения не нужна: команды используют его Python напрямую.

Если у вас установлен `uv`:

```powershell
uv venv .venv --python 3.12
uv pip install --python .venv\Scripts\python.exe -r requirements-text.txt
.\.venv\Scripts\python.exe -X utf8 text_downloader.py --help
```

## Параметры Python CLI

```powershell
.\.venv\Scripts\python.exe -X utf8 text_downloader.py --help
```

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `--url URL` | Ссылка на карточку книги; обязательна без `--from-cache` | — |
| `--login LOGIN` | Почта или логин; можно не указывать и ввести по запросу | Запрос в терминале |
| `--output PATH` | Каталог результата | `books` в текущем каталоге |
| `--name NAME` | Имя файлов без расширения | `book` |
| `--format both` | Сохранить EPUB и PDF | `both` |
| `--format epub` | Сохранить только EPUB | — |
| `--format pdf` | Сохранить только PDF | — |
| `--headful` | Показать Chrome | Выключено |
| `--cache PATH` | Сохранить текст и изображения для повторного экспорта | Выключено |
| `--from-cache PATH` | Экспорт из существующего кэша без входа | Выключено |

Параметра для передачи пароля нет. `--login` необязателен: интерактивный ввод позволяет не оставлять адрес почты в истории команд.

PowerShell-обёртка поддерживает `-Url`, `-Login`, `-Name`, `-Output`, `-Headful`. Для выбора одного формата или работы с кэшем используйте Python CLI.

### Только EPUB

```powershell
.\.venv\Scripts\python.exe -X utf8 text_downloader.py `
  --url 'https://www.litres.ru/book/author/book-123456/' `
  --format epub --name 'my-book'
```

### Сохранить кэш и повторить экспорт

```powershell
.\.venv\Scripts\python.exe -X utf8 text_downloader.py `
  --url 'https://www.litres.ru/book/author/book-123456/' `
  --cache '.cache\my-book' --name 'my-book'

.\.venv\Scripts\python.exe -X utf8 text_downloader.py `
  --from-cache '.cache\my-book' `
  --format epub --output 'books-v2' --name 'my-book'
```

Кэш содержит **сам текст книги и изображения**. Его не следует публиковать. При чтении из кэша сверяются контрольные суммы изображений; при повторной сборке PDF нужен Chrome, при повторной сборке только EPUB — нет.

## Как устроена загрузка

1. Chrome открывает обычную форму входа Литрес.
2. Программа находит ссылку текстовой читалки на карточке книги.
3. Cookies текущей сессии передаются локальному HTTP-клиенту для запросов к `litres.ru`.
4. Загружаются оглавление `toc.js` и перечисленные в нём части. JSON5 разбирается без исполнения полученного JavaScript.
5. Проверяются непрерывность диапазонов и число блоков. Ошибка или пропущенная часть прерывает сборку.
6. Получаются и проверяются изображения, разметка переводится в XHTML.
7. EPUB упаковывается локально; PDF печатается Chrome из локального HTML.
8. Итоговые файлы переносятся из временного каталога в выбранный каталог результата.

После штатного завершения Chrome закрывается. Программа не использует ваш постоянный профиль Chrome и не изменяет его сохранённые пароли.

## Конфиденциальность

- В исходниках нет учётных данных. Пароль запрашивается через `getpass`; отдельного файла с паролем программа не создаёт.
- Cookies используются для запросов текущей сессии и не экспортируются в пользовательский конфигурационный файл.
- Chrome работает с временным профилем; браузер может записывать данные сессии во временный каталог во время работы. После аварийного завершения временные файлы могут сохраниться.
- В кэш записываются книга и иллюстрации, но не логин, пароль или cookies.
- `verification.json` содержит название, автора, ID произведения, статистику и контрольные суммы. Это метаданные вашей выгрузки: не публикуйте их без необходимости.
- `.gitignore` использует список разрешённых файлов. Книги, кэши, `.env`, логи, браузерные профили и случайные новые файлы не добавляются обычной командой `git add`.
- Скрипт `scripts/check_publication.py` проверяет список отслеживаемых файлов и типовые признаки секретов. Это дополнительная проверка, а не доказательство отсутствия любых возможных чувствительных данных.

Подробнее: [SECURITY.md](SECURITY.md). Перед публикацией своих изменений проверяйте `git diff --cached`, а не только `.gitignore`.

## Ограничения

- Поддерживается **текстовая** читалка; аудиокниги и читалка сканированных PDF не реализованы.
- Нужен доступ к книге. Ознакомительный фрагмент и закрытая книга не являются источником полной выгрузки.
- Вход через Google, VK и другие внешние сервисы не реализован.
- Структура сайта может измениться; программа зависит от формы входа и формата данных читалки.
- PDF имеет новую пагинацию A4 и не воспроизводит издательский макет.
- Качество иллюстраций ограничено качеством файлов читалки.
- Ссылки внутри текста, для которых читалка не передала адрес, остаются текстом.
- Неизвестные типы разметки вызывают остановку вместо молчаливого пропуска.
- Возобновления прерванной сетевой загрузки по отдельным частям нет; `--from-cache` предназначен для уже сохранённого полного кэша.
- Все изображения находятся в памяти до экспорта; большие иллюстрированные книги могут потребовать заметного объёма RAM.

## Частые проблемы

| Сообщение / ситуация | Что проверить |
| --- | --- |
| `python` или `uv` не найдены | Установку Python 3.12 и доступность команды в новом окне PowerShell |
| Нельзя запустить `.ps1` | Используйте ручной запуск через Python, описанный выше |
| Не удаётся получить ChromeDriver | Наличие Chrome, доступ к интернету, настройки прокси/межсетевого экрана |
| Вход не завершён | Правильность учётных данных; вход вручную в браузере; `--headful` для диагностики |
| Ссылка на текстовую читалку не найдена | Адрес карточки, доступ к книге и наличие текстового формата |
| Сервер не разрешил доступ | Доступ к книге в аккаунте и состояние сессии |
| Неполные данные или неизвестный тип разметки | Возможное изменение формата читалки; сообщите ошибку без приватных данных |
| Выходной файл уже существует | Измените `--name` либо `--output` |
| Кэш не прошёл проверку SHA-256 | Повторно получите кэш; не используйте повреждённые или чужие данные |

Не прикладывайте к публичному issue пароль, cookies, полный адрес читалки с параметрами аккаунта, кэш или книгу. Достаточно версии Python/Chrome, команды с условными данными и обезличенного сообщения об ошибке.

## Разработка и проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
git add .
.\.venv\Scripts\python.exe scripts\check_publication.py
git diff --cached --check
git diff --cached
```

Тесты выполняются на синтетических данных и проверяют разбор JSON5, пропущенные/перекрывающиеся части, сохранение текста и сносок, структуру EPUB, ссылки, изображения и ограничения путей. Они не требуют аккаунта Литрес, реальных книг или секретов. Перед первой публикацией все 8 тестов прошли локально на Windows с Python 3.12; рабочие файлы и единственный публикуемый коммит были проверены Gitleaks без находок.

GitHub Actions пока не настроен. Для проверки изменений запускайте приведённые выше команды локально.

Сам факт успешных модульных тестов не гарантирует, что сайт Литрес не изменил форму входа или читалку.
